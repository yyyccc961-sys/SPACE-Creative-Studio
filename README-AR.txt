SPACE Creative Studio — ملفات الموقع
=====================================

الملفات:
- index.html: الموقع العام.
- admin.html: لوحة الإدارة المنفصلة.
- style.css: التصميم المتجاوب.
- app.js: تحميل الخدمات والأعمال وإرسال طلبات العملاء.
- admin.js: تسجيل الدخول وإدارة الخدمات والأعمال والطلبات.
- config.js: إعدادات الاتصال بـ Supabase.

الخطوة الأولى: أضف المفتاح العام
1. افتح config.js.
2. استبدل PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE بمفتاح sb_publishable_ الخاص بمشروعك.
3. لا تضع أي sb_secret_ أو service_role key في هذا الملف.

الخطوة الثانية: جرّب محلياً
ارفع الملفات إلى مستودع GitHub جديد أو مستودع موقع SPACE الحالي.
افتح index.html عبر GitHub Pages للموقع العام.
لوحة الإدارة تكون على /admin.html.

ملاحظات مهمة:
- لوحة الإدارة تعتمد على Supabase Auth. سجّل الدخول بحساب المدير الذي أنشأته في Authentication > Users.
- لا تشارك كلمة مرور المدير.
- الروابط للصور والفيديو تُضاف عبر رابط عام يبدأ بـ https://؛ رفع الملفات مباشرة غير مفعّل في هذه النسخة.
- أمان لوحة الإدارة يعتمد على سياسات RLS في قاعدة البيانات. راجع السياسات وتأكد أن حساب UID المحدد هو حساب المدير الوحيد.
- سياسات SQL لا تمنع أي شخص من محاولة إرسال طلبات كثيرة إلى نموذج التواصل؛ أضف حماية من الرسائل المزعجة قبل إطلاق الموقع.
- إذا ظهر خطأ عند حفظ الإعدادات، تحقق من وجود سياسات INSERT/UPDATE المناسبة في site_settings.
- إذا كنت قد نفذت سياسات سابقة تحمل الأسماء نفسها، لا تنفذ CREATE POLICY ثانية بنفس الأسماء.
- مفاتيح Supabase العامة (publishable/anon) مخصصة للواجهة عند ضبط RLS. المفاتيح السرية ممنوع وضعها في ملفات الويب أو GitHub.
